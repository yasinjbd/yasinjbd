## درباره من

من نرم‌افزارهای درجه‌یک تولیدی می‌سازم — از سیستم‌های بک‌اند مقاوم تا رابط‌های کاربری که استفاده ازشون راحته. برام معماری‌ای که با گذر زمان خراب نمی‌شه، کد قابل‌خوندن، و تحویل چیزهایی که واقعاً اهمیت دارن مهمه.

- 🏢 مهندس نرم‌افزار ارشد، تمرکز فعلی روی سیستم‌های توزیع‌شده
- 🌱 در حال یادگیری Rust و الگوهای پیشرفته Kubernetes
- 🤝 مشاور مهندسین جوان‌تر در وقت آزادم
- 💬 هر سوالی درباره معماری بک‌اند، طراحی سیستم یا ابزارهای توسعه داشتی بپرس
